# StarShark Complete Site

Open `index.html` to start.

Included:
- Approved marketing homepage
- Signup and login
- Onboarding
- Dashboard
- Customers
- Reviews
- Automations
- Shark Patrol
- Integrations
- Analytics
- Billing
- Team
- Settings
- Privacy/Terms placeholders

The approved marketing, dashboard, and Shark Patrol artwork are used as exact visual references where available.

This package is a complete front-end product prototype. Real production behavior still requires:
- Supabase project + schema + auth/RLS
- Stripe products/prices + webhooks
- Twilio messaging + A2P/consent handling
- Email provider
- Housecall Pro / Jobber OAuth + webhooks
- Google Business Profile integration
- Deployment to GitHub/Vercel

No secret credentials are embedded.


Homepage header navigation has been fully wired: logo, Features, Integrations, Pricing, Resources, Log In, and Start Free Trial are interactive.
